# Small-simple-network

Objective

-Design a small simple business network which allows connectivity between multiple including Administration, IT and HR departments.

Network Configuration and Implementation

1) VLAN configuraton
2) 802.1q trunking
3) ROAS configuration
4) DHCP configuration
5) IPv4 addressing

Verification Results

1) Multiple PCs from different VLANs setup to receive dynamic IP addressing
2) Operational subinterfaces to allow inter-vlan routing
3) Successful pings between PCs in different VLANs
